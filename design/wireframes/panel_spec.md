# 右栏面板实现说明（浏览器 / Git / 产物）

线框：`panel_{browser,git,artifacts}.html`（共用 `panel.css`，URL 加 `#dark` 切深色），截图 `panel_*_{light,dark}.png`（1280×800）。
颜色一律用 `src/braid/theme/tokens.json` 的 token 名；原则同 design_spec：无标题栏、无边框、无分隔线，只用留白 + 渐变 + 柔和阴影分区。

## 1. 整体
- 左栏 240（`sb_a→sb_b` 横向渐变）；中栏自适应，最小 480，底 `bg_app`；右栏默认 420（320–720 可拖），底 `pn_a→pn_b` 横向渐变，与中栏之间只用一层向左的极淡阴影（`-8px 0 24px -12px #00000014`），不画线。
- 右栏内边距：左右 18，底 18；区块之间纵向间距 12。
- 卡片：`surface` 底、圆角 14、阴影 `0 1px 3px #0000000F, 0 6px 18px #0000000D`（深色 `#00000040 / #00000033`）。

## 2. 标签行 + 窗口控制按钮
- 高 52，内边距 左 18 / 右 10，标签间距 4。
- 标签：高 28，左右内边距 12，圆角 10，字号 13（ui）。普通 `text2`；hover `hover` 底；当前 `active` 底（#E9E9E8 / #3A3A39）+ `text` + 600 字重。
- 窗口控制按钮组浮层定位在窗口右上角：每个 28×28、间距 2、距右边 10、与最后一个标签间距 ≥16；按钮中心与标签文字中线对齐（即与 28 高的标签同中心）。颜色 `wc_fg`，hover `wc_hover` 底圆角 8，关闭 hover `wc_close_hover` 底 + `wc_close_fg` 图标（QSS `role=windowControl` / `kind=close` / `[hovered=true]`）。
- 左上角不放三个小点；面板收起后按钮回到中栏右上角，尺寸边距不变。中栏标题右侧 ◨ 按钮开关面板。

## 3. 浏览器
- 地址栏一行高 28：后退 / 前进 / 刷新（28×28 图标按钮，圆角 10，`text2`；不可用时 `text3` + 60% 透明），URL 输入框（`hover` 底、圆角 10、等宽 12px，聚焦时 2px `brand` 焦点环），右端“在系统浏览器打开”↗。
- 网页区：卡片，占满剩余高度，内容裁剪在圆角内。
- Agent 操作中：
  - 底部状态条浮在网页卡片内（左右底各 16），`surface` 底、圆角 12、阴影；左侧 8px `brand` 圆点 + 4px `sel` 光晕（呼吸动画 1.2s），文案“Agent 正在操作 · <动作>”`text2` 12px，右侧“接管”按钮（`control` 底，点击后暂停 agent 并交还鼠标）。
  - 点击高亮框：目标元素外扩 2px，`brand` 2px 描边 + 6px `sel` 外晕，圆角 12；下方 11px `brand` 标签“点击 · 选择器”。点击后 600ms 淡出。
  - 空闲时状态条与高亮全部隐藏；加载中刷新按钮变停止 ✕，地址栏底部 2px `brand` 进度条。

## 4. Git
- 顶行：分支 chip（`control` 底、圆角 12，⎇ 名称 ▾，点击弹分支菜单，复用菜单样式），ahead/behind `text3` caption；右侧 Pull / Push 次级按钮（`control`，圆角 10）。执行中按钮显示转圈并禁用。
- 文件列表卡片：分组标题“暂存（n）/ 未暂存（n）”caption `text3`；行高 28、圆角 10、内边距 4×8，路径等宽 12 `text2`，右侧状态字母 12/600：A `success`、M `warning`、D `danger`。hover `hover` 底；选中 `active` 底 + `text`。hover 时行尾出现 +/− （暂存/取消暂存）。
- Diff 卡片：占剩余高度，等宽 12/20；首行 caption“路径 · +x −y”；行号 26 宽 `text3`；加行底 success 12% 透明（`#2E8B571F` / `#5CC28A26`），删行底 danger 10–15%（`#C0392B1A` / `#E2685B26`），文字 `text`。无选中文件时显示占位“选择文件查看改动”。
- 提交区：卡片，单行可扩展输入（最多 6 行），占位“提交信息（Ctrl+Enter 提交）”；主按钮 `accent`/`accent_text`“提交 n 个文件”，暂存为空或信息为空时禁用（`control` 底 + `text3`）。

## 5. 产物
- 上方预览卡片（占剩余高度）：标题文件名 13/600；右上分段控件 预览/源码/Diff（`control` 底圆角 10、内边距 3，选中段 `surface` 底 + 阴影，圆角 8）。内容区 `subtle` 底圆角 12；Markdown/HTML 渲染、图片适应窗口、代码走代码块样式；Diff 同 Git 面板样式，无前版本时该段禁用。
- 底部操作：复制、在文件夹中显示（次级），下载（主按钮，右对齐）。复制成功后按钮文字 1.5s 内变“已复制 ✓”。
- 列表：标题“本次会话产物（n）”caption；卡片间距 8，内边距 8×12，圆角 14；32×32 图标块（`subtle` 底圆角 10），文件名 13 `text`，“大小 · 生成时间” caption `text3`。hover 阴影加深；选中 `active` 底、去阴影。新产物生成时插到顶部并淡入。无产物时显示空状态“本次会话还没有产物”。
